# Guion para el video de entrega

Duración máxima: 3 minutos. Graba en `.mp4` o `.mov`, con la terminal en letra grande, y verifica que el archivo pese menos de 500 MB.

1. **0:00–0:20:** abre el frontend público y la ruta `/health` del backend.
2. **0:20–0:40:** cambia un texto visible del título y guarda el cambio.
3. **0:40–1:00:** crea un commit pequeño y envíalo a GitHub.
4. **1:00–2:15:** ejecuta `./deploy.sh` y muestra los seis pasos. Si el backend gratuito despierta o el build tarda, acelera esa parte o recorta la espera.
5. **2:15–2:30:** recarga el frontend y enseña el cambio publicado.
6. **2:30–3:00:** opcionalmente muestra el error claro de `./deploy.sh --check` cuando falta una variable, sin mostrar ningún secreto.

Antes de grabar, ensaya una vez y cierra las pestañas o ventanas que muestren tokens, conexiones de Neon o archivos `.env`.
